# Pikko

Simple commerce platform for independent sellers. **Sell your way.**

## Stack

- **Web:** Next.js, TypeScript, Tailwind, Radix/shadcn, Lucide
- **API:** Go, PostgreSQL
- **Email:** Brevo (transactional)
- **Deploy:** Docker Compose on VPS behind a reverse proxy

## Quick start

See [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md) and [docs/DEVELOPMENT_PROGRESS.md](docs/DEVELOPMENT_PROGRESS.md).

```bash
cp .env.example .env
docker compose up --build
```

Local development without Docker is documented in `docs/DEPLOYMENT.md`.
